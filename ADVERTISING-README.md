# VITEC Scoreboard Advertising Media

The video output menu provides three independent Game Broadcast layouts:

- Game Broadcast: no advertising space.
- Game Broadcast + L-Bar Ads: left rail and bottom banner.
- Game Broadcast + Bottom Bar Ad: bottom banner only.

## Recommended media dimensions

| Output | Right rail | Bottom banner |
| --- | --- | --- |
| 3840 × 2160 | 840 × 1680 | 3840 × 480 |
| 1920 × 1080 | 420 × 840 | 1920 × 240 |
| 1280 × 720 | 280 × 560 | 1280 × 160 |

The left rail uses a 1:2 aspect ratio. The bottom banner uses approximately an 8:1 aspect ratio. Other sizes are accepted, but the media uses a fill treatment and may be cropped at the edges.

Media within 3% of the recommended aspect ratio is displayed unchanged. Media outside that tolerance is scaled and center-cropped automatically at display time. This adjustment is non-destructive: VITEC Scoreboard preserves the original uploaded file.

Supported formats are PNG, JPG, WebP, GIF, MP4, and WebM. Each file may be up to 250 MB. Advertising video is muted and loops automatically.
