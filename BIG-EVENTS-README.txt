VITEC Scoreboard v0.7.8 Big Events

Built on the stable v0.7.7 image/live-game branch.

Adds:
- Larger live batter/pitcher portraits
- Full Live Game event overlay
- HOME RUN alert with player image
- GRAND SLAM alert
- RUN SCORES alert
- DOUBLE / TRIPLE
- STOLEN BASE
- STRIKEOUT
- DOUBLE PLAY
- PITCHING CHANGE
- Automatic fade back to Live Game

The event detector uses current live GameCenter data and last-play descriptions.
It does not change the stable MLB backend or Windows Service registration.

Updater:
  installer\Update-Big-Events.cmd
