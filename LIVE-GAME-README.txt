VITEC Scoreboard v0.7.6 Live Game View

Purpose:
- Make Live Game the default GameCenter experience during active games.
- Keep Pitch Analytics available as a second tab.
- Preserve the stable v0.7.4/v0.7.5 service/backend behavior.

New default Live Game view:
- current batter vs pitcher
- balls / strikes / outs
- base runners
- last play
- last pitch
- compact current-matchup strike zone
- recent matchup pitch action

Tabs:
- Live Game
- Pitch Analytics

Update:
  installer\Update-Live-Game.cmd

The updater does not delete/recreate the Windows Service.
