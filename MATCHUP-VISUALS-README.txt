VITEC Scoreboard v0.8.4 Matchup Visuals

Adds a richer center-panel matchup display:

- larger batter image
- larger pitcher image
- enlarged strike-zone visualization
- Live Pitches mode
- At-Bat Heat Map mode
- Game Heat Map mode
- existing last-pitch type / velocity / result
- existing live GameCenter backend retained

The heat maps are generated by VS from MLB plateX / plateZ pitch data.
MLB does not need to provide a pre-rendered heat-map image.
