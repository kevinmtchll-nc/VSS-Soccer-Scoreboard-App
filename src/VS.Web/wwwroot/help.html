VITEC Soccer Scoreboard Help

MLS scoring, MatchCenter, and broadcast output

ScoreboardSettings

Addresses

Soccer application: http://localhost:5100

Configuration and logs: C:\ProgramData\VITEC Soccer Scoreboard

Data

MLS schedules and MatchCenter data are provided through the configured soccer provider. Team crests use the licensed Sportradar Images API when configured.

Video

The dedicated soccer helper renders MLS scoreboard and MatchCenter scenes for UDP multicast or SRT output. Configure FFmpeg and select an MLS match under Settings.
