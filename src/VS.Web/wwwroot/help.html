MLS Data

MLS schedules and MatchCenter data are supplied through the configured soccer provider. Current club images are proxied from MLSsoccer.com, with optional locally uploaded overrides.

JSON and XML Integration

Machine-readable feeds can include the daily schedule and an optional selected MatchCenter.

PostgreSQL History

Use the History page to capture a match date and replay stored MLS MatchCenter snapshots, including lineups, events, statistics, and expected goals.

Video

The dedicated soccer helper renders MLS scoreboard and MatchCenter scenes for UDP multicast or SRT output. Configure FFmpeg and select an MLS match under Settings.
